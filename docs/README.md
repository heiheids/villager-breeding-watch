## 阅读建议

- **只想用**：看「使用说明」的第四～六节（按键、设置、怎么看）和第八节（限制）。
  遇到"没反应"，直接跳到第九节，先跑 `tools/diag-log.ps1`。
- **想改**：先看「技术说明」第三节（26.3 的 API 事实）和"七之二"（时间与节拍的硬规则），
  再看「经验与踩坑」第零节 —— 那两条规则是被真机事故逼出来的，违反必然静默失效。
- **接手/移植**：把「经验与踩坑」整份读完，尤其是"编译能过、运行没反应"的那一类。
